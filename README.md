# أصوات النقب – منصة تحليل القائمة العربية الموحدة

منصة ويب تفاعلية (عربية، مناسبة للموبايل) لتحليل أصوات البلدات العربية في النقب منذ انتخابات 2019، مع:

- **الملخص**: المؤشرات الرئيسية لكل جولة، واستنتاجات تلقائية، ورسوم بيانية لكل الجولات.
- **البلدات**: جدول لكل البلدات (38 بلدة وقرية وعشيرة)، مع مقارنة حسب النوع و"خريطة أولويات" (تجنيد / إقناع / معقل)، وحساب الأصوات المحتملة.
- **ماذا لو؟**: محاكي يغيّر نسبة التصويت ونسبة الدعم والأصوات الباطلة ويُظهر الأثر على الأصوات والمقاعد ونسبة الحسم.
- **توقعات 2030 و2034**: حسب النمو في عدد أصحاب حق الاقتراع، مع 3 سيناريوهات جاهزة وإمكانية التحكم في كل افتراض.
- **المنهجية**: المصادر والمعادلات والقيود، وتنزيل كل المعطيات بصيغة CSV.

كل سيناريو يمكن مشاركته برابط (القيم محفوظة في الرابط).

## المصادر

معطيات رسمية فقط: لجنة الانتخابات المركزية للكنيست ودائرة الإحصاء المركزية. التفاصيل في [`data/SOURCES.md`](data/SOURCES.md).

## هيكل المشروع

```
data/raw/                      الملفات الرسمية كما هي
data/negev_arab_localities.csv تصنيف البلدات العربية في النقب
scripts/build_data.py          يحوّل الملفات الرسمية إلى docs/data/negev.json + فحوصات تطابق
docs/                          الموقع (ثابت، بدون build) – يُنشر عبر GitHub Pages
  js/model.js                  كل المعادلات
  js/app.js                    الواجهة
tests/model.test.mjs           فحوصات المعادلات
```

## تشغيل محلي

```bash
python3 -m http.server 8000 -d docs
```

ثم افتح http://localhost:8000

## تحديث المعطيات (مثلًا بعد انتخابات جديدة)

1. نزّل `expc.csv` للجولة الجديدة من `https://mediaNN.bechirot.gov.il/files/expc.csv` إلى `data/raw/kNN_expc.csv`.
2. أضف الجولة إلى `ELECTIONS` و`OFFICIAL_RAAM_VOTES` في `scripts/build_data.py` (أحرف القائمة وعدد المقاعد الرسمي).
3. شغّل:

```bash
python3 scripts/build_data.py
```

```bash
node --test tests/*.test.mjs
```

السكربت يتوقف بخطأ إذا لم تطابق المجاميع الأرقام الرسمية.
